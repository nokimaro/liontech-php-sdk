## [Unreleased]

### Added
- Initial release of LionTech PHP SDK
- Complete API coverage: Orders, Payments, Refunds, Payouts, Tokens, Transfers, Balances
- Domain-oriented request/response DTOs
- Webhook signature verification helper
- Card encryption helper
- Token refresh support
- Comprehensive exception handling
- PHP 8.3+ with strong typing
- PSR-4, PSR-7, PSR-17, PSR-18 compatibility
- Extensive documentation and examples
- Unit test suite
